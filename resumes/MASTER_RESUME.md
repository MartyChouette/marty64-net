Licensed BSL 1.1.

**Medium (bullet-friendly, for technical resumes):**
- Architected and shipped a 100k+ line C++20/Vulkan game engine with a complete ImGui-based editor, 70+ ECS components, and build pipeline
- Implemented a Vulkan PBR renderer with cascaded shadow maps, clustered forward lighting, GPU occlusion culling, and full hardware ray tracing (shadows, reflections, AO, GI, path tracing, 3 denoisers)
- Integrated dual physics backends (Jolt 5.2.0, Box2D 3.0.0), AngelScript scripting (721 bindings), and blueprint-style visual scripting with 146+ nodes
- Built a 30+ effect post-processing stack, retro rendering modes (PSX, Dreamcast), and 44 starter templates
- Developed accessibility suite: 8 colorblind corrections, remappable input, screen reader, switch access, dwell-click, dyslexia mode
- Published under BSL 1.1 with full documentation, installer, and standalone game player

**Long (portfolio/cover letter):**
TEGE (The Enjin Game Engine) is an aesthetics-first open source game engine I designed, directed, and debugged as a solo developer. Built with C++20 and the Vulkan graphics API, it ships a complete ImGui editor with play mode, undo/redo, 44 starter templates, and a command palette. The engine supports 70+ ECS component types, dual physics backends (Jolt 3D, Box2D 2D), AngelScript scripting with 721 API bindings, and a blueprint-style visual scripting editor. The Vulkan renderer includes PBR materials, cascaded shadow maps, clustered forward lighting, GPU frustum and occlusion culling, a 30+ effect post-processing pipeline, retro rendering modes, and a full hardware ray tracing pipeline with path tracing and three denoiser options. I built an accessibility suite covering colorblind correction, remappable input, screen reader support, switch access, and motor accessibility - designed to meet WCAG AAA standards. The engine includes a build pipeline that packs games into distributable archives, with export targets including standalone executables, HTML5/WebAssembly, and Newgrounds.
