Our Opinions

Aesthetics & Accessibility, First and Foremost

Most engines treat how your videogame looks and who can play it as things you figure out at the end. TEGE puts them first, and everything else in the engine is built around that.

Aesthetics Come First

How your videogame looks and feels is not a polish pass at the end, it is where TEGE starts. Switch between 8 handcrafted render modes (PBR, PS1 retro, hand-painted, cel-shaded, pixel art, sketch, analog CRT) from a single dropdown, no shader math required.

Accessibility Is Built In, Not Bolted On

Every videogame made in TEGE ships with colorblind modes, full input remapping, switch access, OpenDyslexic font toggles, and screen reader support out of the box. You do not have to build any of it yourself, and every player gets to play what you make.

Making Videogames, Demystified

You do not need a computer science degree to make a videogame. Start from ready-to-run templates covering common genres, wire up logic with visual node scripting, and open the code with AngelScript whenever you are curious what is underneath.

Opinions We Build By
  • Aesthetics come first: One-click visual style presets & customizable post-processing.
  • Accessibility comes first: Vision, motor, cognitive, & audio features in every videogame.
  • Making videogames should be demystified: Starter templates, drag-and-drop editing, & visual node scripting.
  • Shipping should be simple: One-click export for Windows desktop and WebGPU web browser.
Things We Refuse to Do
  • Overwhelming enterprise menus and intimidating setup screens.
  • Requiring shader math just to make a stylized retro videogame.
  • Surprise royalty fees or restrictive commercial terms.
  • Locking accessibility features behind external plugins or expensive middleware.

⚡ 2. Visual Scripting, AngelScript & ECS

Visual Node Scripting

Connect logic visually without writing code. Perfect for beginners and artists designing interactions, quest triggers, and state machines.

720+ AngelScript API Bindings

C++ performance with rapid script hot-reloading. Programmers get complete control over gameplay, custom components, and math.

Flash API & Transpiler

Built-in Flash API compatibility layer, AS2/AS3 transpiler, and native Newgrounds.io integration for instant web revival videogames.

🎮 3. Physics & Character Controllers

Jolt 3D & Box2D Physics

Industry standard Jolt Physics (3D) and Box2D (2D) backends with support for ragdolls, destructibles, vehicles, and 6 joint types.

6 Character Controller Types

Pre-built controllers out-of-the-box: 2D Platformer, 2D Top-Down, 3D FPS, 3D Third Person, 3D Top-Down, and Vehicle.

Node Graph Editors

Visual node graphs for Shader Editing (54 node types), Behavior Trees, Dialogue Trees, Quest Progression, and Audio Events.

🚀 Quickstart (10 minutes)

STEP 1

Download & Extract

Download TEGE-0.9.7.zip (12 MB). Extract and launch the standalone editor binary.

STEP 2

Pick a Template

Choose a starter project (2D Platformer, FPS, Retro PS1, Top-Down, etc.).

STEP 3

Script & Design

Use AngelScript or visual node scripting. Pick an Art Style preset from the dropdown.

STEP 4

Export & Ship

Build a standalone Windows executable or export to WebGPU HTML5 web package with 1 click.

💻 Hardware & System Requirements

Windows Desktop Requirements

  • OS: Windows 10 or Windows 11 (64-bit)
  • Graphics: Dedicated GPU with Vulkan 1.3 support
  • RAM: 4 GB RAM minimum
  • Storage: ~250 MB disk space

WebGPU Browser Requirements

  • Supported Browsers: Chrome 113+, Edge 113+
  • Experimental: Firefox & Safari WebGPU flags
  • WASM: WebAssembly execution enabled
